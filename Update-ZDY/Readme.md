## 🚀 Скрипт автоматического обновления zapret-discord-youtube

### 📦 Назначение
Два скрипта для бесшовного обновления уже установленной версии [zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube).  
Скачайте новую версию, распакуйте содержимое в папку `update` внутри основного каталога и запустите `update.bat` **от имени администратора**.

### ✨ Что делает update.bat
(В ДВУХ СЛОВАХ - ПЕРЕНОСИТ НОВУЮ ВЕРСИЮ ПОВЕРХ ВАШЕЙ, СОХРАНЯЯ ВСЕ ВАШИ НАСТРОЙКИ И ЛИСТЫ)
- Проверяет наличие Cloudflare WARP (`warp-cli`) и при возможности переводит туннель на протокол **MASQUE**.
- Запускает PowerShell-скрипт `update.ps1`, который:
  - объединяет текстовые списки из папок `update/lists` и `update/utils` с существующими;
  - заменяет все `.bat`-файлы (кроме самого `update.bat`);
  - обновляет папку `bin`;
  - заменяет `test zapret.ps1` в `utils`;
  - удаляет временные файлы и очищает папку `update`.

### ⚙️ Требования
- **ОС:** Windows 10/11
- **Права администратора** — обязательны
- **Основная программа:** установленный [zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube/releases)
- **Cloudflare WARP** — опционально (если нет — скрипт просто пропустит настройку MASQUE, обновление продолжится)
- **PowerShell 5.1+** (есть из коробки в Windows 10/11)

### 📥 Установка и использование
1. Скачайте и распакуйте новую версию `zapret-discord-youtube` (релизный архив) **в отдельную папку**.
2. Найдите папку с **установленной** утилитой. Если в ней ещё нет пустой папки `update` — создайте.
3. **Скопируйте всё содержимое** скачанной новой версии внутрь этой папки `update`.
4. Поместите в корень утилиты файлы `update.bat` и `update.ps1` (из этого релиза).
5. Запустите `update.bat` от имени администратора.
